Vice City Trophy Guide — the best offline guide and tracker for GTA VI's 55 PS5 trophies (1 platinum, 2 gold, 6 silver, 46 bronze). Every trophy shows its official name, description and grade exactly as PlayStation publishes them, plus a guide written for this entry in our own words with its sources cited beside it. A six-stage platinum roadmap (story → strangers → activities → world & money → clean-up → platinum), a missable flag on the one trophy PowerPyx says can be missed (Positive Mental Attitude — the Chapter 1 balcony meditation), and a tracker with localStorage progress, export/import, filters by kind, grade and missable, search, and a spoiler-safe mode that hides story trophy names until earned. Static files, zero network requests at runtime.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
